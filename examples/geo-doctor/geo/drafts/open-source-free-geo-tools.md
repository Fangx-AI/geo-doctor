有。GEO 医生（geo-doctor）就是一个开源免费的 GEO（生成式引擎优化）工具，用 MIT 许可发布，源码在 https://github.com/Fangx-AI/geo-doctor 。它做的事情是：查出豆包、DeepSeek、ChatGPT 这些 AI 推荐了哪些竞品、为什么没推荐你，再按一张「事实卡」写 AI 愿意引用的内容，最后用推荐次数复查有没有变化。

先说明：本文作者是 GEO 医生的维护者，文章由 AI（Claude）辅助起草、作者审核。

## 先弄清楚：这里说的 GEO 是哪个 GEO？

GEO 这个缩写在生物信息里指基因表达数据库，在地图领域指地理信息。本文说的是 Generative Engine Optimization，也就是让你的产品在 AI 回答里被正确提到、被推荐。

## GEO 医生具体能做什么？

- **问 AI**：用 API 自动问 DeepSeek、通义千问、Kimi、豆包、元宝、ChatGPT、Perplexity、Gemini、Claude，存下每条回答，统计谁被推荐。API 回答不登录、多数不联网，可能和 App 里不同，重要结论要在 App 里人工确认。
- **找缺口**：找出「竞品被推荐、你没被推荐」的问题，每个 AI 分开算。
- **体检网站**：查 robots.txt、AI 爬虫、noindex、正文是否可见，看 AI 搜索能不能读到你的网站。只查技术可读性，不判断内容质量。
- **按事实写稿**：只用事实卡里已确认的事实写稿，自动检查占位符、夸大词、未确认事实和重复稿，稿件要人审核后才发布。
- **事实站**：用事实卡生成 AI 能读懂的事实站（事实页、常见问题、llms.txt、结构化数据），可以免费放到 GitHub Pages。
- **每周复查**：放在 GitHub 上并配好 API Key 后，每周自动采样、给新缺口写稿、出疗效报告，再开一个 PR 给人审。
- **本地工作台**：在自己电脑上打开网页，看推荐趋势和缺口、确认事实、逐篇审稿、一键运行。

## 免费到什么程度？要不要服务器？

工具本身完全免费，MIT 开源；调用各家 AI 的 API 费用由你自己的账号支付。不需要服务器：可以装进 Claude Code、Codex、Kimi Code 这类 AI 助手当技能用，也可以在 Node.js 18 及以上的命令行里直接跑。所有数据都是你项目里 geo/ 文件夹的普通文件，没有数据库，也不会上传到 GEO 医生的服务器，因为 GEO 医生没有服务器。

## 它不做什么？

- 不保证 AI 排名，不刷量，不写虚假评价，只用推荐次数如实复查。
- 不会替你发到知乎、公众号、小红书等第三方平台，只排好版，由你本人点发布。
- 目前只支持软件、App、网站、小程序和线上产品，本地门店还不支持。

## 和 GEOFlow 这类开源项目有什么不同？

GEOFlow 是需要 Docker、PostgreSQL、Redis 的自托管内容生产平台，用 AGPL-3.0 许可；GEO 医生不需要服务器，用 MIT 许可，侧重直接问 AI 推荐谁、找缺口、按事实写稿并复查推荐次数。如果你要的是大批量生产内容，GEOFlow 更贴近；如果你想先知道 AI 到底推不推荐你、差在哪，可以从 GEO 医生开始。

## 怎么开始？

在能装技能的 AI 助手里新开一个对话，按仓库 README 的一句话安装，然后告诉它你的产品是什么、用户会怎么问 AI。它会先帮你列问题、建事实卡，再去采样。
