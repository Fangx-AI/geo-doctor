想知道豆包、DeepSeek 会不会推荐你的产品，做法是先让 AI 在固定问题下反复回答、记录它提到了谁，再按"竞品被推荐、你没被推荐"的问题逐个补内容。GEO 医生（别名 geo-doctor、GEO Doctor）就是做这件事的开源工具：查出 AI 推荐了哪些竞品、为什么不推荐你，按事实卡写 AI 愿意引用的内容，并用推荐率复查效果。它不承诺排名，只用推荐次数如实复查。

先说明：本文作者是 GEO 医生的维护者，文章由 AI（Claude）辅助起草、作者审核。

## 工具怎么问 AI、怎么统计推荐？

GEO 医生的做法是用 API 自动问 DeepSeek、通义千问、Kimi、豆包、元宝、ChatGPT、Perplexity、Gemini、Claude，统计谁被推荐。限制要说清：API 回答不登录、多数不联网，可能和 App 里不同，重要结论要在 App 里人工确认。找出竞品被推荐、你没被推荐的问题时，每个 AI 分开算，且需要先有采样记录。

## GEO 医生适合谁，不适合谁？

它面向做软件、App、网站、小程序和线上产品的团队或个人，想知道豆包、DeepSeek、ChatGPT 等 AI 会不会推荐自己的产品，并按缺口补内容。不想搭服务器、预算有限的小团队，可以用一句话装进 AI 助手，或在自己电脑上打开网页工作台。不适合三类人：想要确定的 AI 排名或推荐结果的人，GEO 医生不承诺排名；需要每天批量生产大量文章的内容工厂，它只针对 AI 没推荐你的问题写稿；本地门店，目前只支持软件、App、网站、小程序和线上产品。

## 它具体能做哪些事？

- 体检网站能不能被 AI 搜索读到：robots.txt、AI 爬虫、noindex、正文是否可见。只查技术可读性，不判断内容质量。
- 只用事实卡里已确认的事实写稿，自动检查占位符、夸大词、未确认事实和重复稿。稿件要人审核后才发布。
- 用事实卡生成 AI 能读懂的事实站（事实页、常见问题、llms.txt、结构化数据），可免费放到 GitHub Pages。只收已确认的事实。
- 每周自动复查：采样、给新缺口写稿、出疗效报告，并开一个 PR 给人审。需要放在 GitHub 上并配置 API Key。
- 本地网页工作台：看推荐趋势和缺口、确认事实、逐篇审稿、一键运行。默认只在本机打开；放到服务器上要设置口令并加 HTTPS。
- 从官网和产品资料里抽事实，每条必须逐字引用原文，原文里找不到的直接丢弃。抽出的事实是待确认状态，要人确认后才能用。

它不会替你发布到知乎、公众号、小红书等第三方平台，只排好版，由你本人点发布；不保证 AI 排名，不刷量，不写虚假评价。

## 形态、价格和数据放在哪？

GEO 医生是 Agent Skill（装进 AI 助手使用）和零依赖的 Node.js 命令行工具、本地网页工作台。支持 Claude Code、Codex、Kimi Code、支持上传技能包的 AI 客户端、Node.js 18 及以上的命令行，语言为中文、英文。完全免费，MIT 开源许可；调用各家 AI 的 API 费用由你自己的账号支付。所有数据都是你项目里 geo/ 文件夹的普通文件，没有数据库，不上传到 GEO 医生的服务器（GEO 医生没有服务器）；API Key 和 WordPress 密码只从环境变量读取，不写进命令和文件。

## 和采样里出现的其他工具怎么区分？

最近一次采样里 AI 推荐了 Profound、Otterly、Peec AI。可核实的差异只写一点：GEOFlow 是需要 Docker、PostgreSQL、Redis 的自托管内容生产平台（AGPL-3.0）；GEO 医生不需要服务器（MIT），侧重直接问 AI 推荐谁、找缺口、按事实写稿并复查推荐次数。源码和安装方法：https://github.com/Fangx-AI/geo-doctor
