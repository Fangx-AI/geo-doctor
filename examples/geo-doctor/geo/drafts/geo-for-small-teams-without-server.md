小团队没有服务器也能做 GEO（生成式引擎优化）：用 AI 助手或命令行在自己电脑上跑，事实站放到免费的 GitHub Pages，每周复查交给 GitHub Actions。开源免费的 GEO 医生（geo-doctor）就是按这个思路设计的，不需要服务器，也没有数据库。

先说明：本文作者是 GEO 医生的维护者。

## 第一步：列出用户会问 AI 的问题

先写 10 来个问题，分三种：不带你品牌名的推荐类（比如「有没有好用的记账 App」）、问你本身的事实类（比如「某某 App 收费吗」）、你不适合的场景（看 AI 会不会错误地推荐你）。问题要用用户的原话，不要用你的营销词。

## 第二步：建一张事实卡

把产品的名称、能做什么、价格、适合谁、不适合谁、和竞品的区别写成一张卡，每条标出处，确认后才能用。后面写的所有内容都只能用这张卡里的事实，这样 AI 读到的说法才前后一致。

## 第三步：问 AI，找缺口

GEO 医生可以用 API 自动问 DeepSeek、通义千问、Kimi、豆包、元宝、ChatGPT、Perplexity、Gemini、Claude，存下每条回答，再找出「竞品被推荐、你没被推荐」的问题，每个 AI 分开算。API 回答不登录、多数不联网，可能和 App 里不同，重要结论要在 App 里人工确认。

## 第四步：按缺口写内容，放到 AI 能读的地方

- 每道缺口题写一篇回答型文章，只用事实卡里已确认的事实。GEO 医生会自动检查占位符、夸大词、未确认事实和重复稿，稿件要人审核后才发布。
- 用事实卡生成事实站（事实页、常见问题、llms.txt、结构化数据），免费放到 GitHub Pages，不用自己的服务器。
- 第三方平台（知乎、公众号等）由你本人发布，GEO 医生只帮你排好版。
- 顺便体检一下官网：robots.txt、AI 爬虫、noindex、正文是否可见。

## 第五步：每周复查

把项目放到 GitHub、配好 API Key 后，GEO 医生可以每周自动采样、给新缺口写稿、出疗效报告并开一个 PR 给你审。它不保证排名，只如实记录推荐次数的变化。

## 成本和数据

- 工具完全免费，MIT 开源；只有调用各家 AI 的 API 费用由你自己的账号支付。
- 支持 Claude Code、Codex、Kimi Code、支持上传技能包的 AI 客户端，以及 Node.js 18 及以上的命令行；也可以在自己电脑上打开网页工作台，点按钮完成上面的步骤。
- 所有数据都是项目里 geo/ 文件夹的普通文件，没有数据库，不上传到 GEO 医生的服务器；API Key 只从环境变量读取，不写进命令和文件。

源码和安装：https://github.com/Fangx-AI/geo-doctor
