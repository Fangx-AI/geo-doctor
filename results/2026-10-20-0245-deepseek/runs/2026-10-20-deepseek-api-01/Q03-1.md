# Q03 · 第 1 次

## 问题

怎么检查我的网站能不能被 AI 搜索读到？

## 回答

# 检查网站能否被 AI 搜索读到的方法

AI 搜索（如 ChatGPT、Perplexity、Google AI Overviews、Claude 等）的抓取逻辑和传统搜索引擎**不完全一样**，需要分几个层面检查。

## 一、检查抓取权限（最基础）

### 1. 查看 robots.txt 是否放行 AI 爬虫
访问 `你的域名/robots.txt`，检查是否误封了这些主流 AI 爬虫：

```
GPTBot          # OpenAI / ChatGPT
OAI-SearchBot   # OpenAI 搜索
ChatGPT-User    # ChatGPT 实时浏览
ClaudeBot       # Anthropic
PerplexityBot   # Perplexity
Google-Extended # Google AI (Gemini训练/概览)
Applebot-Extended
CCBot           # Common Crawl
Bytespider      # 字节
```

❌ 常见错误：`Disallow: /` 一刀切封禁所有 Bot，把 AI 也挡了。

### 2. 测试爬虫实际访问
用 curl 模拟 AI 爬虫 UA：

```bash
curl -A "Mozilla/5.0 AppleWebKit/537.36 (KHTML, like Gecko; compatible; GPTBot/1.0; +https://openai.com/gptbot)" https://你的域名/
```

看是否返回 200 和正常内容（不是 403 / 验证页 / 空壳）。

### 3. 检查是否被 CDN / WAF 拦截
Cloudflare、Akamai 等默认会拦部分 AI Bot，需在后台确认 **Bot Management** 没把它们挡掉。

## 二、检查内容可读性（关键）

AI 爬虫**不执行复杂 JS**（多数情况），只能读到 HTML 里的静态内容：

| 检查项 | 说明 |
|---|---|
| **SSR / 静态渲染** | 用 `curl` 或「查看网页源代码」（Ctrl+U）看正文是否在 HTML 里。若只有 `<div id="app"></div>`，AI 读不到 |
| **纯文本可读性** | 关掉 CSS/JS 后内容是否完整（浏览器插件 "Web Developer" 可一键禁用） |
| **语义化 HTML** | 用 `<h1>/<h2>/<article>/<p>` 而非全 `<div>` |
| **结构化数据** | 加 JSON-LD（Article、FAQ、Product、Organization）提升被引用概率 |

## 三、检查是否已被收录

### 1. 直接问 AI
- **Perplexity / ChatGPT（联网）**：`site:你的域名 关键词`，看是否出现你的页面
- **Google AI Overviews**：搜你的品牌词/核心问题，看是否被引用

### 2. 查第三方索引
- **Common Crawl**：`https://index.commoncrawl.org/CC-MAIN-2024-XX-index?url=你的域名/*&output=json`
- **Bing Webmaster Tools**：Bing 索引是 ChatGPT 搜索的重要来源，务必提交 sitemap
- **Google Search Console**：AI Overviews 基于 Google 索引

### 3. 专用检测工具
- **llms.txt 检查**：访问 `你的域名/llms.txt`（新兴的 AI 可读性声明文件，非强制但有用）
- **AI 可见性工具**：Profound、Otterly、Peec AI 等可监测品牌在 AI 回答中的提及率

## 四、快速自查清单

```
□ robots.txt 未封禁主流 AI Bot
□ 服务器对 AI UA 返回 200 + 完整 HTML
□ 核心内容在 HTML 源码中（SSR/SSG）
□ 有 sitemap.xml 并提交到 Bing / Google
□ 有结构化数据（JSON-LD）
□ 页面加载无验证码/Cookie 墙阻挡
□ 考虑加 llms.txt 声明
```

## 五、两个易踩的坑

1. **Cookie 弹窗 / 年龄验证墙** → AI 爬虫读不到正文，尽量让内容先进 DOM。
2. **只做客户端渲染的 SPA** → 建议上 Next.js/Nuxt 等 SSR 方案，或为爬虫提供预渲染。
