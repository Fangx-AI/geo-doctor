# Q01 · 第 2 次

## 问题

有没有开源免费的 GEO 工具？

## 回答

GEO（Generative Engine Optimization，生成式引擎优化）是近两年随 AI 搜索兴起的新领域，开源工具生态还在快速演进中。目前完全开源免费的**专用 GEO 平台**还比较少，但有不少可组合使用的开源工具能覆盖 GEO 的核心需求。下面按功能分类介绍：

## 一、GEO 监测与可见性追踪

**1. LLM 品牌可见性监测（自建）**
- 目前没有成熟的"开箱即用"开源 GEO 监测平台，但可以用开源框架自建：
  - **LiteLLM**（开源，统一调用 OpenAI/Claude/Gemini/DeepSeek 等 API）——批量向多个 LLM 提问品牌相关问题，统计品牌被提及频率
  - **LangChain / LlamaIndex**——编排"提问→收集回答→提取品牌实体→统计"的流水线
  - **Streamlit / Gradio**——快速搭监测看板

**2. 传统 SEO 开源工具（GEO 基础数据仍可用）**
- **Screaming Frog**（免费版限 500 URL）——抓取站点结构
- **Lighthouse / PageSpeed Insights**（开源）——页面性能
- **Unlighthouse**（开源）——批量跑 Lighthouse
- **Sitebulb**（有免费试用，非开源）

## 二、结构化数据与内容优化（GEO 核心）

GEO 的关键是让 AI 爬虫/检索系统"读懂"内容，开源工具：

- **Schema.org 校验**：Google Rich Results Test（免费）、**schema-dts**（开源 TypeScript 类型）
- **JSON-LD 生成**：**schema-generator**、各 CMS 的开源插件
- **Markdown 化 / 内容结构化**：**Pandoc**（开源）批量转换；**Unstructured**（开源）做文档解析
- **llms.txt 生成器**：社区有多个开源小工具（GitHub 搜 `llms-txt generator`），用于给 AI 爬虫提供站点摘要

## 三、AI 爬虫可访问性检测

- **robots.txt 分析**：**reppy**（Python 开源库）解析 robots.txt，检查是否误封 GPTBot、ClaudeBot、PerplexityBot 等
- **日志分析**：**GoAccess**（开源）分析服务器日志，看 AI 爬虫抓取情况
- **Cloudflare / 自建 WAF** 日志 + **Grafana**（开源）可视化

## 四、内容质量与 E-E-A-T 辅助

- **Grammarly 替代**：**LanguageTool**（开源）语法检查
- **可读性**：**textstat**（Python 开源）
- **事实核查**：**ClaimBuster**（学术开源）

## 五、竞品与引用分析

- **引用追踪**：目前无成熟开源方案，可自建——用 **LiteLLM** 批量问 AI"推荐 XX 领域工具"，记录回答中出现的品牌/链接
- **网页抓取**：**Firecrawl**（开源，可自托管）、**Crawl4AI**（开源）——专门为 LLM 优化抓取，适合抓竞品页面喂给 AI 分析

## 六、数据看板

- **Metabase / Superset / Grafana**（全开源）——把监测数据可视化

## 现实建议

1. **纯开源 GEO 平台目前基本空白**，商业产品（如 Profound、AthenaHQ、Otterly）更成熟，但贵。
2. **最实用的开源组合**：
   - `LiteLLM` + `LangChain` + `Firecrawl` + `Streamlit` + `Metabase`，自建"AI 可见性监测 + 内容优化"闭环。
   - 用 `reppy` + `GoAccess` 做爬虫可访问性审计。
3. **关注 GitHub 趋势**：搜 `generative engine optimization`、`llm seo`、`ai search visibility`，社区项目更新很快（如 `geo-optimizer`、`llm-visibility-tracker` 等小项目陆续出现，但成熟度参差，建议先看 star 和 commit 活跃度）。
