# Q01 · 第 1 次

## 问题

有没有开源免费的 GEO 工具？

## 回答

"GEO"这个缩写在不同领域含义差异很大，先帮你梳理一下，看你说的是哪一类：

## 1. 地理空间/地理信息（Geospatial）方向
这是最常见的理解，开源免费工具很成熟：

- **QGIS** — 桌面 GIS 全能选手，插件生态丰富，替代 ArcGIS 的首选
- **GeoServer** — 发布地理数据为 OGC 标准服务（WMS/WFS 等）
- **PostGIS** — PostgreSQL 的空间数据库扩展
- **GDAL/OGR** — 地理数据格式转换的底层库
- **Leaflet / OpenLayers** — 前端地图可视化库
- **MapLibre GL JS** — Mapbox GL 的开源分支
- **Kepler.gl / deck.gl** — 大规模地理数据可视化
- **OSM 生态**（OpenStreetMap、Nominatim 地理编码、OSRM 路径规划）

## 2. GEO = Generative Engine Optimization（生成式引擎优化）
这是近两年 AI 搜索兴起后的新概念（让内容更容易被 ChatGPT、Perplexity 等引用）。开源工具比较少，主要是一些监测/分析脚本，成熟度不高，多为社区项目，需要自行甄别。

## 3. GEO = 地球观测（Earth Observation）
- **Google Earth Engine**（学术免费但非开源）
- **Sentinel Hub / OpenEO** — 部分开源
- **SNAP**（ESA 开源）、**Orfeo ToolBox**

## 4. 其他
- **GEO** 也可能是某个具体产品的缩写（如基因表达数据库 Gene Expression Omnibus，本身免费但非工具）
