# Q03 · 第 2 次

## 问题

怎么检查我的网站能不能被 AI 搜索读到？

## 回答

检查你的网站能否被 AI 搜索（如 ChatGPT、Perplexity、Claude、Gemini 等）读取，可以从以下几个层面系统地排查：

## 一、基础技术检查

**1. robots.txt 是否放行了 AI 爬虫**
查看你站点根目录的 `robots.txt`，注意以下常见 AI 爬虫的 User-Agent：
- `GPTBot`（OpenAI）
- `ChatGPT-User`（ChatGPT 实时浏览）
- `OAI-SearchBot`
- `ClaudeBot` / `anthropic-ai`
- `PerplexityBot`
- `Google-Extended`（Gemini 训练/使用）
- `CCBot`（Common Crawl，很多 AI 依赖它）
- `Bytespider`（字节）

用命令快速查看：`curl https://你的域名/robots.txt`

**2. 服务器是否拦截**
有些 CDN/WAF（Cloudflare、Akamai）默认会拦截非浏览器 UA 或已知爬虫。检查防火墙日志里是否有这些 UA 的 403/429。

**3. 页面是否可被无 JS 渲染**
AI 爬虫大多**不执行 JavaScript**。用 `curl` 或浏览器禁用 JS 后访问，看正文内容是否还在 HTML 里。如果是纯 SPA，需要 SSR/预渲染方案。

**4. HTTP 状态与可访问性**
确保返回 200、无强制登录墙、无 CAPTCHA、无地区封锁。

## 二、内容结构检查

**5. 语义化 HTML**
标题用 `<h1>`–`<h6>`，正文用 `<p>`，列表用 `<ul>/<ol>`，避免整页 div 堆砌。

**6. 结构化数据**
加上 Schema.org 的 JSON-LD（Article、FAQPage、Product、Organization 等），AI 更易解析。

**7. 内容可读性**
- 关键信息不要藏在图片里
- 表格用真正的 `<table>`
- 避免大段 iframe

## 三、实测方法

**8. 用 curl 模拟 AI 爬虫**
```bash
curl -A "GPTBot/1.0" https://你的域名/页面 | head -200
curl -A "PerplexityBot" https://你的域名/页面 | grep -i "<title>"
```
看返回是否正常、正文是否在 HTML 中。

**9. 直接在 AI 里问他**
- 在 ChatGPT / Perplexity 里搜索你的品牌名 + 关键页面标题，看是否被引用。
- 在 Perplexity 输入你的网址，看它能否抓取。
- ChatGPT 联网模式下问"总结 example.com 这个页面"。

**10. 用第三方工具**
- **Google Search Console** 的 URL 检查（索引好通常 AI 也能读）
- **Bing Webmaster Tools**（ChatGPT 检索部分依赖 Bing 索引）
- **Ahrefs / Semrush** 的 AI 可见性报告（新功能）
- **llms.txt** 相关检测工具
- **Cloudflare AI Audit**（如果站点在 CF 上）

**11. 检查是否被主流索引收录**
AI 搜索多依赖索引层：`site:你的域名` 在 Bing / Google 里是否有结果。

## 四、加分项

**12. 提供 `llms.txt`**
在根目录放一个 `llms.txt`，说明网站结构和重要页面链接（正在成为事实标准）。

**13. sitemap.xml**
确保存在并在 robots.txt 中声明，方便爬虫发现页面。

**14. 内容是"可引用"的**
清晰的问答结构、明确的数据、作者信息、更新时间，都能提升被 AI 引用概率。

## 快速自检清单

```
□ robots.txt 未屏蔽 GPTBot/ClaudeBot/PerplexityBot/CCBot
□ 关闭 JS 后正文仍在 HTML 中
□ 页面返回 200，无登录墙/CAPTCHA
□ H1/H2/段落语义清晰
□ 有 JSON-LD 结构化数据
□ Bing/Google 已收录
□ curl -A "GPTBot" 能拿到完整内容
□ 在 Perplexity/ChatGPT 中能被引用
```

如果你告诉我网站用的技术栈（比如 Next.js SPA、WordPress、Shopify），我可以给更具体的排查步骤。
