# Q04 · 第 2 次

## 问题

预算一个月 500 块以内，有没有能检查网站能不能被 AI 读到的工具

## 回答

500 块/月以内，能检查网站"能不能被 AI 读到"的工具，其实要看你说的"被 AI 读到"具体指哪一层。我分几种情况说，因为市面上工具覆盖的能力差别很大：

## 先明确"被 AI 读到"的三种含义

1. **AI 爬虫能不能抓取**（GPTBot、ClaudeBot、PerplexityBot 等是否被 robots.txt 放行、能否正常访问）
2. **内容能不能被 AI 理解**（结构化数据、语义 HTML、llms.txt 等）
3. **品牌/内容会不会出现在 AI 回答里**（GEO / AI 可见性监测，即 ChatGPT、Perplexity 回答中是否引用你）

大多数便宜工具只做其中一层，别买错。

## 500 元/月内的可行方案

**第 1 层（爬虫可访问性）——基本可以免费做**
- 手动检查 `robots.txt` 里是否屏蔽了 GPTBot / ClaudeBot / PerplexityBot / Google-Extended 等
- 用 Screaming Frog 免费版（500 URL 以内）抓取，看服务器日志里 AI 爬虫的访问情况
- 这一层几乎没有必要花钱，任何"AI 可读性检测"工具卖的就是这个，自己查更快

**第 2 层（结构化 / llms.txt）**
- 免费工具就能覆盖：Google Rich Results Test、Schema Markup Validator
- llms.txt 目前没有权威检测工具，手动生成 + 检查即可

**第 3 层（AI 可见性监测）——这才是要花钱的地方**
500 元/月预算下，国际工具基本都超预算（Profound、AthenaHQ、Peec AI 起步都在几百美元/月）。可行的选择：
- **国内工具**：一些做 GEO 监测的 SaaS（如部分 AIGC 监测平台）有几百元/月的入门档，但覆盖模型和额度有限，需要试
- **半自助**：用 API 自己跑——ChatGPT / Perplexity 的 API 按量付费，写个脚本定期问"XX 领域推荐哪些品牌/网站"，一个月几十块就够，500 预算完全覆盖。缺点是没现成报表，要自己搭

## 给你的建议

- 如果只是**担心网站被 AI 爬虫挡住**：别花钱，日志 + robots.txt + Screaming Frog 免费版足够
- 如果要**监测品牌在 AI 回答里的出现率**：500 元/月买不到成熟国际工具，建议先用 API 自建或找国内 GEO 工具的入门档试一个月
- 警惕把"AI 可读性检测"包装成高价 SaaS 的产品，很多功能免费工具就能替代
