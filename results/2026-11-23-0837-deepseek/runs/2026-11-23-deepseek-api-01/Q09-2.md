GEO 医生的 skill 能装进 Claude Code 吗

## 回答

可以，但要分情况说明。

## 简短回答

**能装，但不是"原生 skill"的直接安装**——GEO 医生的技能本质上是提示词/工作流 + 外部工具的组合，需要你自己封装成 Claude Code 能识别的形式。

## 具体怎么装

Claude Code 的扩展机制主要有几种，对应不同装法：

### 1. 如果 GEO 医生是纯提示词/方法论
封装成 **Slash Command**（`.claude/commands/` 下的 `.md` 文件）或 **Skill**（`.claude/skills/` 目录，带 `SKILL.md`）。

```bash
# 项目级
.claude/skills/geo-doctor/SKILL.md
# 或用户级（全局可用）
~/.claude/skills/geo-doctor/SKILL.md
```

`SKILL.md` 里写清楚：描述、触发条件、执行步骤、需要的工具。

### 2. 如果 GEO 医生依赖外部 API / 数据库 / 爬虫
需要用 **MCP Server** 把它包一层，然后在 `~/.claude/settings.json` 或项目 `.mcp.json` 里注册，Claude Code 通过 MCP 协议调用。

### 3. 如果它是一套 CLI 工具
直接用 **Bash 工具** 调用即可，在 skill 描述里写清调用方式。

### 4. 如果它是某个平台的插件（Claude.ai 的 Project / GPT 等）
**不能直接迁移**。需要把里面的提示词、知识库、工具调用逻辑手动提取出来，重新按上面 1-3 的方式落地。
