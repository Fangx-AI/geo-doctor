# Q13 · 第 2 次

## 问题

geo-probe 报缺少 API Key 怎么办

## 回答

遇到 `geo-probe` 报缺少 API Key，通常是因为该工具需要调用第三方地理编码或地图服务（如高德、百度、Google Maps 等），但未配置对应的密钥。可以按以下步骤排查和解决：

## 1. 确认 geo-probe 是什么工具
`geo-probe` 不是特别常见的标准工具名，先确认来源：
- 是某个开源项目（GitHub 上的）？
- 是公司内部工具？
- 是某个 npm/pip 包？

不同工具的配置方式不同，但思路一致：**找到它读取 API Key 的环境变量名或配置文件**。

## 2. 常见解决方式

### 方式一：通过环境变量配置（最常见）
```bash
# Linux / macOS
export GEO_PROBE_API_KEY="你的key"
export GEO_API_KEY="你的key"

# Windows (CMD)
set GEO_PROBE_API_KEY=你的key

# Windows (PowerShell)
$env:GEO_PROBE_API_KEY="你的key"
```

具体变量名要看它的文档或源码，常见命名：
- `GEO_PROBE_API_KEY`
- `GEO_API_KEY`
- `AMAP_API_KEY` / `BAIDU_MAP_AK` / `GOOGLE_MAPS_API_KEY`
- `MAPBOX_ACCESS_TOKEN`

### 方式二：配置文件
很多工具支持配置文件，例如：
- `~/.geo-probe/config.yaml`
- `~/.config/geo-probe/config.toml`
- 项目根目录的 `.env` 文件

```env
GEO_PROBE_API_KEY=你的key
```

### 方式三：命令行参数
```bash
geo-probe --api-key 你的key ...
```

## 3. 快速定位它要哪个变量
如果不知道变量名，直接看报错信息或源码：

```bash
# 如果是 npm 包
npm root -g
grep -r "API_KEY" $(npm root -g)/geo-probe

# 如果是 pip 包
pip show geo-probe
grep -r "API_KEY" $(python -c "import geo_probe, os; print(os.path.dirname(geo_probe.__file__))")

# 如果是本地二进制
geo-probe --help
strings $(which geo-probe) | grep -i "api_key"
```

## 4. 获取 API Key
根据它调用的服务申请：
- **高德**：https://console.amap.com/ （Web服务 Key）
- **百度地图**：https://lbsyun.baidu.com/
- **Mapbox**：https://account.mapbox.com/access-tokens/
- **Google Maps**：https://console.cloud.google.com/

## 5. 如果只是本地测试/不想申请
部分工具支持 **mock 模式** 或 **离线模式**：
```bash
geo-probe --offline
geo-probe --mock
```
查看 `--help` 是否有类似选项。
