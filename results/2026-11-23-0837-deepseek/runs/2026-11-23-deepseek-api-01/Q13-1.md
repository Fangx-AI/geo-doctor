# Geo-Probe 报"缺少 API Key"的解决方法

Geo-Probe 本身是一个**前端地理探测工具**,它依赖第三方地图/地理编码服务(如高德、百度、Google Maps、Mapbox、天地图等)的 API Key。报"缺少 API Key"通常就是**没有配置对应服务的密钥**,或者配置位置不对。

## 排查与解决步骤

### 1. 确认用的是哪个服务
先看报错信息的完整内容,通常会指明是哪个 provider,例如:
- `AMap API key is required`
- `Mapbox access token missing`
- `Google Maps API key not found`

不同服务的申请方式不同。

### 2. 去对应平台申请 Key
| 服务 | 申请地址 | 备注 |
|---|---|---|
| 高德地图 | https://console.amap.com/ | 选"Web端(JS API)"类型 |
| 百度地图 | https://lbsyun.baidu.com/ | 需实名认证 |
| 天地图 | https://console.tianditu.gov.cn/ | 政府/个人均可 |
| Mapbox | https://account.mapbox.com/ | 免费额度 |
| Google Maps | https://console.cloud.google.com/ | 需绑定信用卡 |

### 3. 配置 Key 的三种常见方式

**方式 A:环境变量(.env 文件)**
```bash
# 在项目根目录创建 .env
VITE_AMAP_KEY=你的key
VITE_MAPBOX_TOKEN=你的token
```
> 注意:Vite 项目必须以 `VITE_` 开头,`create-react-app` 用 `REACT_APP_`,`Nuxt` 用 `NUXT_PUBLIC_`。

**方式 B:配置文件**
找到 `config.js` / `config.json` / `settings.js` 之类,填入:
```js
export default {
  amapKey: '你的key',
  mapboxToken: '你的token'
}
```

**方式 C:界面设置**
部分 Geo-Probe 版本有设置面板(齿轮图标),可以直接粘贴 Key。

### 4. 常见坑

- **改了 .env 没重启**:环境变量只在启动时加载,改完必须 `npm run dev` 重启。
- **Key 类型选错**:Web 端项目必须申请"Web端(JS API)"的 Key,不能用地移动端或服务端的。
- **域名白名单**:高德/百度控制台里要配置你本地域名(如 `localhost`)和线上域名,否则会报 `INVALID_USER_DOMAIN`。
- **Key 泄露**:前端项目 Key 会暴露在浏览器里,务必在控制台设置**域名白名单 + 用量限制**。
- **Key 过期/欠费**:云服务商欠费后 Key 会失效。

### 5. 如果只是本地测试想跳过
某些版本支持"离线/演示模式",可以:
- 在 URL 后加 `?demo=1`
- 或把 provider 切换为 `OpenStreetMap`(免费无需 Key)
- 或设置 `VITE_GEO_PROBE_PROVIDER=osm`
