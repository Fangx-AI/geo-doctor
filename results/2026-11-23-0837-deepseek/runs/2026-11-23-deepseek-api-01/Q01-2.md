# Q01 · 第 2 次

## 问题

有没有开源免费的 GEO 工具？

## 回答

“GEO 工具”这个说法有歧义，可能指两类完全不同的东西，我分别说：

## 1. 如果你指 **GEO = 地理空间（Geospatial）工具**

这类开源免费工具非常成熟：

**桌面/GIS 软件**
- **QGIS** — 最主流的开源桌面 GIS，插件生态庞大
- **GRASS GIS** — 偏栅格分析与科研
- **SAGA GIS** — 地形/水文分析强

**数据处理与编程库**
- **GDAL/OGR** — 地理数据格式转换的事实标准
- **PROJ** — 坐标系投影转换
- **GeoPandas / Shapely / Rasterio**（Python）
- **sf / terra / raster**（R）
- **PostGIS** — PostgreSQL 的空间扩展

**地图服务与可视化**
- **GeoServer** — 发布 WMS/WFS 地图服务
- **MapServer**
- **Leaflet / OpenLayers / MapLibre GL** — 前端地图库
- **Kepler.gl / deck.gl** — 大规模地理数据可视化

**遥感/影像**
- **Google Earth Engine**（非开源但免费学术使用）、**OpenEO**、**Sentinel Hub** 部分开源
- **Orfeo ToolBox**、**SNAP**（ESA 开源）

## 2. 如果你指 **GEO = 生成引擎优化（Generative Engine Optimization）**

即针对 ChatGPT、Perplexity、AI 搜索结果做优化的工具——这类**目前几乎没有成熟的开源免费方案**。原因：

- 数据源（各家 AI 搜索的引用/排名）不公开，工具多靠爬取或 API，成本高
- 现有商业工具（Profound、Otterly、AthenaHQ 等）都闭源
- 开源侧只有零散脚本，比如用 Python 调 Perplexity/OpenAI API 批量检测品牌提及，需自己搭

可行的小方案：自己写脚本，用各 AI 的 API 定期查询关键词、解析回答中的品牌/链接出现情况，用 Streamlit 做个面板。没有现成开箱即用的。
