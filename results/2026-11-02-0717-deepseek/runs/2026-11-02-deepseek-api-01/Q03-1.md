# Q03 · 第 1 次

## 问题

怎么检查我的网站能不能被 AI 搜索读到？

## 回答

检查网站能否被 AI 搜索（如 ChatGPT、Perplexity、Google AI Overviews、Claude 等）读到，可以从以下几个层面逐一排查。

## 1. 检查 robots.txt 是否屏蔽了 AI 爬虫

打开 `你的域名/robots.txt`，看是否有针对以下 User-Agent 的 `Disallow`：

- `GPTBot`（OpenAI）
- `ChatGPT-User`
- `OAI-SearchBot`
- `ClaudeBot` / `anthropic-ai`
- `PerplexityBot`
- `Google-Extended`（影响 Gemini/AI Overviews）
- `CCBot`（Common Crawl，很多模型训练数据来源）
- `Bytespider`、`Amazonbot` 等

**如果这些被 Disallow，AI 就抓不到你的内容。** 需要的话主动放行：

```
User-agent: GPTBot
Allow: /

User-agent: PerplexityBot
Allow: /
```

## 2. 检查页面级 meta 标签

```html
<meta name="robots" content="noindex, nofollow">
```

如果页面有 `noindex`，搜索引擎和多数 AI 检索都会跳过。检查是否有全局或模板级的误设置。

## 3. 检查是否被登录墙/JS 阻塞

- AI 爬虫大多**不执行 JavaScript**（Google 除外，但 AI Overviews 也受限）。如果你的内容靠 JS 渲染，AI 可能读到空白页。
- **测试方法**：用 `curl -A "GPTBot" https://你的页面` 看返回的 HTML 里有没有正文内容。
- 如果正文是空的 → 考虑服务端渲染（SSR）或预渲染。

## 4. 用真实 UA 模拟抓取

在终端里模拟各爬虫访问：

```bash
curl -A "Mozilla/5.0 AppleWebKit/537.36 ... GPTBot" https://yoursite.com/page
curl -A "PerplexityBot" https://yoursite.com/page
curl -A "ClaudeBot" https://yoursite.com/page
```

看返回状态码（200 才好）、是否有内容、是否被 WAF/CDN 拦截（403/429）。

## 5. 检查 CDN / WAF 是否误杀

Cloudflare、Akamai 等默认可能拦截"可疑"bot。检查：

- Cloudflare → Security → Bots → 是否开启了 "Block AI bots"（新功能，会默认拦截）
- 查看防火墙日志里有没有 GPTBot/ClaudeBot 被 block 的记录

## 6. 主动验证：直接问 AI

最直接的测试：

- 在 **Perplexity** 里搜 `site:你的域名 关键词`，看能否引用你的页面
- 在 **ChatGPT（带搜索）** 里问"总结一下 example.com 关于 XX 的内容"
- 在 **Google** 搜 `site:你的域名`，看 AI Overview 是否出现

如果 AI 能引用你的内容 → 说明抓得到。

## 7. 查看服务器日志

在 access log 里 grep：

```bash
grep -iE "GPTBot|ClaudeBot|PerplexityBot|Google-Extended|CCBot" access.log
```

有记录 → 爬虫来过；全是 403/404 → 有问题。

## 8. 结构化数据加分项

虽然不影响"能否被抓到"，但影响"是否被引用"：

- 加 JSON-LD（Article、FAQPage、Organization）
- 清晰的标题层级（H1/H2）
- 可读的纯文本段落（AI 爱摘段落）

## 快速自查清单

| 检查项 | 命令/位置 | 通过标准 |
|---|---|---|
| robots.txt | `/robots.txt` | 无 Disallow AI bot |
| meta robots | 页面源码 | 无 noindex |
| JS 渲染 | `curl -A GPTBot` | 正文可见 |
| WAF | CDN 后台 | 未 block AI bot |
| 日志 | access.log | 有 bot 访问 200 |
| 实测 | Perplexity/ChatGPT | 能引用你的页面 |

如果你告诉我具体用了什么建站方式（WordPress / Next.js / 静态站 / Cloudflare 等），我可以给出更精确的排查步骤。
