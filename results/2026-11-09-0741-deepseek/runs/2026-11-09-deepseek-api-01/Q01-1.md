# Q01 · 第 1 次

## 问题

有没有开源免费的 GEO 工具？

## 回答

GEO（Generative Engine Optimization，生成式引擎优化）是相对较新的领域，专门针对 ChatGPT、Perplexity、Google AI Overviews 等 AI 搜索引擎做优化的**成熟开源工具还比较少**，但有一些相关方向的开源项目可以参考：

## 一、内容与结构化优化相关

| 工具 | 用途 | 说明 |
|------|------|------|
| **Schema.org / structured-data linters** | 结构化数据标记 | GEO 核心是让 AI 易解析，Schema 标记很关键 |
| **Markdown/MDX 工具链** | 内容格式优化 | AI 爬虫更易解析纯文本/语义化 HTML |
| **Lighthouse / Unlighthouse** | 页面质量审计 | 间接影响 AI 抓取质量 |
| **llms.txt 生成器** | 面向 LLM 的站点说明 | 新兴标准，有多个开源实现（如 `llms-txt` 相关 GitHub 仓库） |

## 二、AI 可见性 / 引用监测（开源方案较少）

- **Perplexity/OpenAI API + 自建脚本**：目前最实用的方式——用开源脚本批量向 ChatGPT/Perplexity/Claude 提问你的目标关键词，记录品牌是否被提及/引用。GitHub 上有一些个人项目（搜 `AI visibility tracker`、`LLM brand monitor`），但都不成熟。
- **SearXNG**：开源元搜索引擎，可用于监测传统搜索 + 部分 AI 结果。
- **LiteLLM**：统一调用多模型的框架，可自建 GEO 监测管线。

## 三、抓取与日志分析

- **GoAccess / Matomo**：分析 AI 爬虫（GPTBot、ClaudeBot、PerplexityBot）的抓取日志
- **Screaming Frog（免费版 500 URL）**：非开源但免费，可审计站点结构

## 四、现实建议

1. **纯 GEO 专用开源工具基本空白**——这是商业机会区（Profound、AthenaHQ、Otterly 等都是闭源 SaaS）。
2. **自建 GEO 监测的最佳开源栈**：
   ```
   Python + LiteLLM + SQLite/Postgres + Streamlit
   ```
   定期跑关键词 → 记录品牌提及/引用 → 看板展示。
3. **关注 GitHub 关键词**：`GEO`、`generative engine optimization`、`AI search visibility`、`llms.txt`，新项目在快速出现。

如果你告诉我具体想做什么（比如监测品牌在 AI 回答中的提及率，还是优化网站让 AI 更容易引用），我可以给更具体的开源组合方案。
