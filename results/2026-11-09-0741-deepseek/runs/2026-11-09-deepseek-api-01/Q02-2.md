# Q02 · 第 2 次

## 问题

怎么知道豆包、DeepSeek 会不会推荐我的产品？有什么工具？

## 回答

想知道豆包、DeepSeek 这类 AI 助手会不会推荐你的产品，核心是搞清楚**AI 搜索/推荐的可观测性**问题。目前没有像传统 SEO 那样成熟的官方工具，但可以从几个层面入手。

## 一、先理解：AI 推荐产品的机制

豆包（字节）、DeepSeek 等推荐产品通常来自：
1. **模型训练数据**中的品牌认知（历史语料）
2. **联网检索**时抓取的网页内容（RAG）
3. **内置生态**（如豆包的抖音/头条内容池）

所以"会不会推荐"取决于：你的产品是否在**可被检索的优质内容**中出现，以及是否在**训练语料**中有足够声量。

## 二、可用的检测方法/工具

### 1. 手动批量测试（最直接、免费）
- 设计一批**用户真实会问的问题**（如"XX 品类哪个牌子好""推荐一款 XX"），在豆包、DeepSeek、Kimi、文心一言、通义千问里逐一提问
- 记录：是否提及你、提及位置、竞品是谁、引用来源链接
- 建议用表格做**基线快照**，定期（每周/每月）复测

### 2. AI 搜索监测类工具（新兴，部分免费）
- **Profound**（海外，专注 AI 搜索可见性监测，支持 ChatGPT/Perplexity 等）
- **Otterly.AI**、**Peec AI**、**AthenaHQ**：AI 搜索品牌监测
- **Semrush / Ahrefs** 近两年推出的 AI 可见性模块（部分覆盖）
- 国内目前**没有成熟的对口工具**，豆包/DeepSeek 的推荐监测基本靠手动或自建脚本

### 3. 自建脚本监测（推荐给有技术资源的团队）
- 用各家 API（DeepSeek 有开放 API；豆包有火山引擎方舟 API）批量跑问题集
- 固定 prompt + 多次采样（AI 输出有随机性，需跑 N 次统计提及率）
- 输出：提及率、平均排名、情感倾向、引用来源
- 这是目前**最可控**的方案

### 4. 内容侧的可观测指标（间接判断）
- 你的官网/百科/知乎/小红书内容是否被 AI 联网检索到（问 AI"信息来源"看引用）
- 品牌词在**知乎、百度百科、小红书、B 站**的覆盖度——这些是中文 AI 高频检索源
- 用百度/谷歌搜 `site:` + 你的品牌，看索引质量

## 三、实操建议

1. **先做基线**：列出 20–50 个核心问题，手动在 5 个 AI 里跑一遍，记下现状
2. **建监测表**：问题 × 平台 × 是否提及 × 排名 × 引用源，每周更新
3. **有技术就上 API 脚本**：DeepSeek API 便宜，豆包方舟 API 也可用，跑批量采样最靠谱
4. **海外业务**可试 Profound / Otterly 类工具；国内目前以自建为主
5. **优化侧**：把产品信息做成结构化、可被检索的内容（百科、问答、评测、对比文），提升被 RAG 抓取的概率

## 四、注意坑

- **AI 输出有随机性**，单次测试不可信，要多次采样看概率
- **豆包的推荐受字节生态影响大**，抖音/头条内容权重高，需针对性布局
- **DeepSeek 更依赖联网检索质量**，官网和权威信源更重要
- 目前**没有官方"推荐查询"接口**，任何声称能"保证 AI 推荐"的服务都要谨慎
