# Q01 · 第 2 次

## 问题

有没有开源免费的 GEO 工具？

## 回答

开源免费的 GEO（Gene Expression Omnibus，基因表达数据库）工具其实不少，主要分为**数据下载/预处理**、**差异表达分析**、**可视化**和**综合流程**几类。下面按用途给你梳理一些主流且活跃的项目。

## 一、数据下载与预处理

| 工具 | 语言 | 说明 |
|------|------|------|
| **GEOquery** | R/Bioconductor | 最经典的 GEO 数据获取包，支持 SOFT/MINiML 解析、GSE/GSM/GPL 下载 |
| **GEOmetadb** | R | 将 GEO 元数据导入 SQLite，方便批量 SQL 查询 |
| **pysradb** | Python | 虽主打 SRA，但可配合 GEO 使用，批量获取元数据 |
| **ffq** | Python | 从 GEO/SRA/ENA 批量抓取 FASTQ 下载链接 |
| **SRA Toolkit** | CLI | 官方工具，配合 GEO 的 SRA 数据下载 |

## 二、差异表达与芯片分析

| 工具 | 语言 | 说明 |
|------|------|------|
| **limma** | R/Bioconductor | 芯片差异表达的黄金标准 |
| **DESeq2 / edgeR** | R | RNA-seq 计数差异分析（GEO 中 RNA-seq 数据常用） |
| **GEO2R** | Web（NCBI 官方） | 在线直接对 GEO 数据集做 limma 差异分析，免费无需安装 |
| **geoparser** | Python | 解析 GEO 系列矩阵文件，快速提取表达矩阵 |
| **GREIN** | Web/R | 在线重新分析 GEO 与 SRA 数据 |

## 三、可视化与挖掘

| 工具 | 说明 |
|------|------|
| **GEOexplorer** | 基于 Bioconductor 的在线/本地探索工具，含差异分析、富集、生存分析 |
| **iDEP** | 在线 RNA-seq 分析平台，可导入 GEO 数据 |
| **NetworkAnalyst** | 在线基因表达与网络分析，支持 GEO 导入 |
| **ClusterProfiler** | R 包，GEO 差异基因的功能富集与可视化标配 |

## 四、综合流程/自动化

- **GEOmetadb + GEOquery + limma**：最经典的开源组合，可脚本化批量处理
- **Snakemake / Nextflow 流程**：社区有 GEO 批量分析模板
- **ArrayExpress/BioConductor 工作流**：跨库兼容

## 推荐入门组合

如果是刚上手，建议：

1. **GEO2R**（零代码快速看差异基因）
2. **GEOquery + limma + clusterProfiler**（R 脚本，可复现、可批量）
3. **GEOexplorer**（想要交互式界面又不想装环境时）

## 注意事项

- NCBI 对 GEO 下载有频率限制，批量下载建议加 `Sys.sleep()` 或用 `rentrez` 做限流。
- 部分 GEO 数据集只提供处理后的矩阵（无原始 FASTQ），分析前需确认数据类型（芯片/RNA-seq/单细胞）。
- 单细胞 GEO 数据可配合 **Seurat**（R）或 **Scanpy**（Python）使用。
