# Q03 · 第 1 次

## 问题

怎么检查我的网站能不能被 AI 搜索读到？

## 回答

检查网站能不能被 AI 搜索（如 ChatGPT、Perplexity、Claude、Google AI Overviews 等）读到，可以从几个层面来验证。下面按"从易到难"给你一套可操作的检查清单：

## 一、最直接的方法：问 AI 本身

- **在 ChatGPT/Perplexity/Claude 里直接搜索**：输入 `site:你的域名`（Perplexity 支持），或直接问"你能访问 example.com 吗？它的主页内容是什么？"
- **让 AI 引用你的品牌名/网址**：比如"请总结 https://你的域名 的内容"，看它是否能给出准确信息，还是会说"无法访问"或编造内容。
- **对比测试**：用同样的问题在多个 AI 工具里问，看哪些能读到、哪些读不到。

## 二、检查 robots.txt（最关键）

AI 爬虫各有自己的 User-Agent，需要在 robots.txt 里放行：

| 爬虫 | User-Agent | 用途 |
|---|---|---|
| OpenAI | `GPTBot` | 训练数据 |
| OpenAI | `OAI-SearchBot` | ChatGPT 搜索 |
| OpenAI | `ChatGPT-User` | 用户实时访问 |
| Anthropic | `ClaudeBot` / `Claude-Web` | Claude |
| Perplexity | `PerplexityBot` | Perplexity |
| Google | `Google-Extended` | Gemini/AI Overviews（训练） |
| Common Crawl | `CCBot` | 多数 AI 的底层语料 |

**检查方法**：访问 `https://你的域名/robots.txt`，看是否意外 `Disallow` 了上述 UA。很多网站为了防抓取屏蔽了 GPTBot，结果连搜索也进不去。

## 三、检查页面是否可被"无 JS"读取

AI 爬虫大多**不执行 JavaScript**（或能力有限）。检查：

- **禁用 JS 后看页面**：浏览器开发者工具 → 禁用 JavaScript → 刷新，看正文是否还在。
- **查看 HTML 源码**（Ctrl+U）：关键内容是否直接出现在 HTML 里，还是全靠 JS 渲染。
- **用 curl 抓取**：`curl -A "GPTBot" https://你的域名/页面`，看返回的 HTML 里有没有正文。

如果内容是 SPA/纯前端渲染，AI 很可能读不到 → 考虑 SSR/SSG 或预渲染。

## 四、检查是否有反爬/防火墙拦截

- **Cloudflare、Akamai 等**的 Bot Fight Mode 常会拦 AI 爬虫。
- **查看服务器日志**：搜索 `GPTBot`、`ClaudeBot`、`PerplexityBot` 的访问记录，看是 200 还是 403/429。
- **用工具模拟**：`curl -I -A "GPTBot/1.0" https://你的域名` 看状态码。

## 五、技术基础检查

- **sitemap.xml 存在且可访问**，并在 robots.txt 里声明。
- **结构化数据（Schema.org）**：Article、FAQ、Organization 等 JSON-LD，帮助 AI 理解内容。
- **页面可公开访问**：不需要登录、没有付费墙（除非 AI 爬虫被特别允许）。
- **HTTPS、加载速度**正常。
- **canonical 标签**正确，避免重复内容。

## 六、用第三方工具验证

- **Google Search Console**：看 Googlebot 抓取情况（Google-Extended 相关）。
- **Bing Webmaster Tools**：Bing 数据也喂给部分 AI。
- **AI 可见性监测工具**：Profound、Otterly.ai、Peec AI、HubSpot AI Search Grader 等，可批量检测你的品牌在各大 AI 里的出现情况。
- **llms.txt**（新兴标准）：在根目录放 `llms.txt` 给 AI 提供站点摘要，虽非官方标准但越来越多人用。

## 七、快速自检清单

```
□ robots.txt 未屏蔽 GPTBot / OAI-SearchBot / ClaudeBot / PerplexityBot / CCBot
□ 禁用 JS 后正文仍可见
□ curl 抓取返回 200 且含正文
□ 服务器日志有 AI 爬虫访问记录（非 403）
□ sitemap.xml 可访问
□ 有 JSON-LD 结构化数据
□ 页面无需登录即可访问
□ 在 ChatGPT/Perplexity 里直接问能读到你的内容
```

---

**最常见的三个坑**：①robots.txt 误屏蔽 GPTBot；②内容全靠 JS 渲染；③Cloudflare 等 WAF 拦截 AI 爬虫。如果你告诉我用的建站方式（WordPress/Next.js/Shopify 等），我可以给更具体的排查步骤。
