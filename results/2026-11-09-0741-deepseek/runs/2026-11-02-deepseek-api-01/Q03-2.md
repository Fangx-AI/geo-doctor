# Q03 · 第 2 次

## 问题

怎么检查我的网站能不能被 AI 搜索读到？

## 回答

检查你的网站能不能被 AI 搜索（如 ChatGPT、Perplexity、Claude、Gemini、Copilot 等）读到，可以从以下几个层面系统排查：

## 1. 检查 robots.txt 是否屏蔽了 AI 爬虫

打开 `https://你的域名/robots.txt`，查看是否有针对以下 UA 的 `Disallow`：

- `GPTBot`（OpenAI）
- `OAI-SearchBot`、`ChatGPT-User`
- `ClaudeBot`、`anthropic-ai`
- `PerplexityBot`
- `Google-Extended`（Gemini 训练/使用）
- `Bingbot`（Copilot 依赖）
- `CCBot`（Common Crawl，很多 AI 的数据来源）

如果有 `User-agent: GPTBot` + `Disallow: /`，就等于主动拒绝了 AI。

## 2. 检查页面是否可被抓取

- **不需要登录**：AI 爬虫不会登录，需要登录才能看的内容 AI 读不到
- **不依赖 JS 渲染**：多数 AI 爬虫不执行 JavaScript。用 `curl` 或关闭 JS 的浏览器访问页面，看正文是否还在
- **无 CAPTCHA / WAF 拦截**：Cloudflare 的 "Bot Fight Mode"、验证码等会挡掉 AI 爬虫
- **无 `noindex`**：检查 `<meta name="robots" content="noindex">` 和 HTTP 头 `X-Robots-Tag`

## 3. 用工具实测

| 工具 | 用途 |
|---|---|
| **Google Search Console** | 看 Bingbot/Googlebot 抓取是否正常（Copilot/Gemini 依赖） |
| **Bing Webmaster Tools** | Copilot 的数据源，检查抓取和索引 |
| **Perplexity** 直接搜索你的品牌/文章标题 | 看是否被引用 |
| **ChatGPT 搜索** 问一个只有你网站才有的问题 | 看是否引用你 |
| **curl 模拟爬虫**：`curl -A "GPTBot" https://你的域名/页面` | 看返回内容和状态码 |

## 4. 检查内容可被"引用"的程度

AI 搜索偏爱结构清晰、可验证的内容：

- 有明确的标题层级（H1/H2）、问答式段落
- 有作者、日期、来源标注（E-E-A-T）
- 有结构化数据（JSON-LD：Article、FAQPage、Organization）
- 内容能被单独摘出来回答一个问题（不是纯营销话术）

## 5. 检查是否被主要索引收录

AI 搜索大多基于已有索引（Bing/Google/Common Crawl）：

- `site:你的域名` 在 Google / Bing 搜一下，看收录量
- 检查 sitemap.xml 是否提交到 Google 和 Bing
- 新站或低权重站可能还没进 Common Crawl

## 快速自检清单

```
□ robots.txt 未屏蔽 GPTBot/ClaudeBot/PerplexityBot/Bingbot
□ 页面无需登录、无需 JS 即可看到正文
□ 无 noindex、无 CAPTCHA、WAF 未拦爬虫
□ Google/Bing 已收录（site: 查询有结果）
□ sitemap 已提交
□ 有结构化数据和清晰的内容结构
□ 用 Perplexity / ChatGPT 搜索品牌或独特内容能命中
```
