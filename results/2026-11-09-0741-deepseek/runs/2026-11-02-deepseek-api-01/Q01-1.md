# Q01 · 第 1 次

## 问题

有没有开源免费的 GEO 工具？

## 回答

GEO（Gene Expression Omnibus）相关的开源免费工具其实不少，主要分几类：数据下载/处理、差异表达分析、可视化、以及综合性的分析流程。下面按用途整理一些比较常用的：

## 数据下载与预处理

- **GEOquery**（R/Bioconductor）：最经典的GEO数据获取包，支持下载GSE、GPL、GSM数据及元信息
- **GEOmetadb**：将GEO元数据导入SQLite数据库，方便批量查询
- **SRA Toolkit**（NCBI官方）：下载原始测序数据（fastq），配合GEO中的SRA编号使用
- **ffq / pysradb**：命令行工具，快速获取SRA/ENA下载链接

## 差异表达与芯片分析

- **limma**（R）：芯片数据差异表达分析的金标准
- **DESeq2 / edgeR**（R）：RNA-seq计数数据差异分析
- **GEO2R**：NCBI官方在线工具（基于limma），无需编程即可做基础差异分析，免费但非本地开源
- **ArrayExpress/Bioconductor workflows**：官方提供的完整分析流程文档

## 综合分析与流程

- **GREIN**：在线GEO重新分析平台，提供R代码下载，开源
- **iGEA / GEOexplorer**：交互式探索工具
- **Snakemake / Nextflow 上的公共RNA-seq流程**（如 nf-core/rnaseq）：可对接GEO/SRA数据做端到端分析

## 可视化

- **ggplot2 + pheatmap / ComplexHeatmap**（R）
- **EnhancedVolcano**：火山图
- **ClusterProfiler**：富集分析（常与GEO数据配合）

## 特别推荐

如果你想要**一站式开源方案**，可以组合：
```
GEOquery（下载）→ limma/DESeq2（差异分析）→ clusterProfiler（富集）→ ComplexHeatmap/ggplot2（可视化）
```
这套完全免费开源，也是绝大多数GEO挖掘论文的实际技术栈。
