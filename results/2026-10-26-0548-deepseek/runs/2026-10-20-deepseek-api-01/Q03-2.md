怎么检查我的网站能不能被 AI 搜索读到？

# 检查网站能否被 AI 搜索读取的方法

AI 搜索（如 ChatGPT、Perplexity、Google AI Overviews、Claude 等）读取网站的方式和传统搜索引擎有相似之处，但也有一些独特考量。以下是系统化的检查方法：

## 一、基础技术检查

### 1. 检查 robots.txt
访问 `你的域名/robots.txt`，确认是否屏蔽了 AI 爬虫：

```
User-agent: GPTBot          # OpenAI 训练/AI 搜索
User-agent: ChatGPT-User    # ChatGPT 实时浏览
User-agent: PerplexityBot   # Perplexity
User-agent: ClaudeBot       # Anthropic
User-agent: Google-Extended # Google AI 训练
User-agent: CCBot           # Common Crawl（很多 AI 的语料来源）
```

如果这些被 `Disallow: /` 屏蔽，AI 就无法读取。

### 2. 检查页面可抓取性
- **无需登录/无付费墙**：AI 爬虫通常不登录
- **无 JS 依赖**：很多 AI 爬虫不执行 JavaScript，内容最好在 HTML 源码中
- **测试**：用 `curl` 或关闭 JS 的浏览器查看页面，看核心内容是否还在

```bash
curl -A "GPTBot" https://你的域名/页面 | grep "关键内容"
```

### 3. 检查 CDN/WAF 是否拦截
Cloudflare、Akamai 等可能默认拦截 AI 爬虫（尤其是 "Block AI bots" 开关）。检查安全规则里是否误拦。

## 二、实际抓取测试

### 4. 用爬虫 UA 模拟访问
```bash
curl -A "Mozilla/5.0 (compatible; GPTBot/1.0; +https://openai.com/gptbot)" https://你的域名
curl -A "Mozilla/5.0 (compatible; PerplexityBot/1.0)" https://你的域名
```
看返回状态码（200 正常，403/429 表示被拦）和内容是否完整。

### 5. 查看服务器日志
搜索日志里的 `GPTBot`、`PerplexityBot`、`ClaudeBot` 等 UA，确认它们**是否真的来过**、抓了哪些页面、返回什么状态码。这比任何工具都真实。

## 三、内容可索引性检查

### 6. 检查 sitemap.xml
- 是否提交到 Google Search Console（AI Overviews 依赖 Google 索引）
- sitemap 是否包含所有重要页面

### 7. 结构化数据
AI 更易理解有 Schema.org 标记的内容（Article、FAQPage、Product 等）。用 [validator.schema.org](https://validator.schema.org) 检查。

### 8. 内容是否"可引用"
- 有清晰的标题层级（H1/H2）
- 段落简洁、有明确事实和答案
- 有作者、日期等 E-E-A-T 信号

## 四、实际验证 AI 是否已收录

### 9. 直接问 AI
在 ChatGPT、Perplexity、Claude 里问：

> "site:你的域名"（部分工具支持）
> "请介绍 [你的品牌名] 的官网内容"
> "根据 [你的域名] 上的信息，回答……"

看它能否**引用你的网站**并给出链接。Perplexity 会显示来源，最容易验证。

### 10. 用 Google Site 搜索 + AI Overviews
搜索你的核心关键词，看是否出现 AI Overview 且引用你的站。

## 五、工具辅助

| 工具 | 用途 |
|------|------|
| **Google Search Console** | 看索引状态、抓取情况 |
| **Bing Webmaster Tools** | ChatGPT 搜索基于 Bing 索引 |
| **[llmstxt.org](https://llmstxt.org) 的 llms.txt** | 新兴的 AI 友好索引文件，可考虑添加 |
| **Perplexity 直接测试** | 最快看引用效果 |
| **Screaming Frog**（改 UA） | 批量模拟 AI 爬虫抓取 |

## 快速自检清单

- [ ] robots.txt 未屏蔽 AI 爬虫
- [ ] CDN/WAF 未拦截 AI UA
- [ ] 关闭 JS 后内容仍可见
- [ ] 服务器日志出现过 AI 爬虫
- [ ] Bing 已收录（ChatGPT 依赖）
- [ ] Google 已收录（AI Overviews 依赖）
- [ ] 有 schema 结构化数据
- [ ] 在 Perplexity/ChatGPT 里能搜到引用
