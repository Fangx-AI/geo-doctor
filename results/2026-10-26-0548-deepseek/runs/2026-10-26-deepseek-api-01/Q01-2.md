# Q01 · 第 2 次

## 问题

有没有开源免费的 GEO 工具？

## 回答

GEO（Generative Engine Optimization，生成式引擎优化）是近两年兴起的概念，主要指优化内容以便被 ChatGPT、Perplexity、Google AI Overviews、豆包等生成式引擎引用和推荐。目前这个领域工具还比较早期，但已经有一些**开源免费**的选择，我按类别整理一下：

## 一、GEO 监测/分析类

**1. GEO-SEO-Analyzer（GitHub 社区项目）**
- 一些个人开发者开源的小工具，用于检测网页内容对 AI 爬虫（GPTBot、ClaudeBot、PerplexityBot 等）的友好度
- 功能通常包括：robots.txt 对 AI bot 的放行检查、结构化数据检测、llms.txt 支持检查

**2. llms.txt 相关工具**
- `llms.txt` 是 2024 年提出的新标准（类似 robots.txt 但面向 LLM）
- 开源生成器：`llms-txt-generator`、`llmstxt`（npm 包）可以自动为网站生成 llms.txt 文件
- 检查工具：`llms-txt-checker`

**3. AI Crawler Checker**
- 开源脚本可检测你的网站是否允许 GPTBot、ClaudeBot、Google-Extended、PerplexityBot、Bytespider 等爬虫访问

## 二、AI 可见性监测类

**4. OpenGEO / GEOKit（社区项目）**
- 部分 GitHub 项目支持批量向 ChatGPT/Perplexity 提问，记录品牌是否被提及
- 需要自备 API Key，成本自负，但代码免费

**5. Perplexity/OpenAI API + 自建脚本**
- 最实用的方案：用 Python 调 OpenAI/Perplexity API，批量 query 关键词，统计品牌提及率
- 参考开源项目：`ai-brand-monitor`、`llm-visibility-tracker`

## 三、内容优化辅助类

**6. Schema.org 结构化数据工具**
- GEO 很依赖结构化数据，开源工具如 `schema-dts`、`structured-data-testing-tool` 可帮助生成/校验 JSON-LD

**7. 开源 CMS 插件**
- WordPress 的 `Yoast SEO`（免费版）已开始加入 AI 搜索相关提示
- `Rank Math` 免费版也有部分 AI 友好度检查

## 四、综合型（较少，需注意甄别）

GitHub 上搜 `GEO`、`generative engine optimization`、`AI SEO` 能找到一些新项目，但多数star数不高、更新不稳定，建议：
- 优先看最近 3 个月有 commit 的仓库
- 优先选 MIT/Apache 协议
- 避免需要上传网站数据的“免费”服务

## 现实建议

目前**没有像 Ahrefs/SEMrush 那样成熟的开源 GEO 全栈工具**。最实用的开源组合是：

```
llms.txt 生成器 + AI bot robots 检查 + 自建 API 监测脚本 + Schema 校验
```
