# 合规红线与行业资质

> 核验日期 2026-10-14。🟢 = 法规或官方原文，🟡 = 媒体报道。法规以最新官方原文为准；拿不准时请用户咨询律师，不要替用户下结论。

## 所有行业都适用

| 规定 | 禁止什么 | 对 GEO 的影响 |
| --- | --- | --- |
| 🟢《网络反不正当竞争暂行规定》第九条（2024-09-01 施行）[原文](https://www.gov.cn/zhengce/202406/content_6959668.htm) | 编造用户评价、返现换好评、伪造口碑、虚假交易、虚假排名 | 不写"顾客评价"类内容，不教用户刷评、买好评 |
| 🟢《互联网信息内容多渠道分发服务管理规定》（2026-09-01 施行）[新华网](https://www.news.cn/politics/20260529/43ea642eefed44c89fdda0ad3d991874/c.html) | 🟡 报道称包括虚构浏览量、点击量、评价评分等数据，以及虚假人设 [光明网](https://m.gmw.cn/2026-09/01/content_1304557259.htm) | 不批量注册账号、不编造"本地人推荐"人设 |
| 🟢《人工智能生成合成内容标识办法》（2025-09-01 施行）[新华网](https://www.news.cn/tech/20250314/f8b96305ff274e0cb70031c2819092ee/c.html) | AI 生成内容须加标识，不得删除标识 | 本工具写的草稿，发布时要按平台要求标注 AI 生成 |
| 🟡 网信办 2026 年 4 月起专项整治"利用 GEO 恶意营销"；2026 年 3·15 曝光 GEO 投毒 | 批量假文章操纵 AI 推荐 | 本工具可以成批写，但每篇对应一道真实缺口题、只用事实卡里已确认的事实，脚本会拦下相似度过高的重复稿；没有官方发布接口的第三方平台只打包，由用户本人用真实账号发布；有官方接口的（dev.to）用用户自己的 Key 发，不模拟登录 |
| 🟢《广告法》第九条 | 广告中使用"国家级""最高级""最佳"等用语 | 官网、文章、应用商店描述都不写"最好、第一、领先" |
| 🟢 预付式消费司法解释（法释〔2025〕4号，2025-05-01 施行）[最高法](https://www.court.gov.cn/zixun/xiangqing/459321.html) | "收款不退"等格式条款无效；付款 7 日内可请求返还本金 | 健身、美业、教培的办卡说明和 FAQ 不能写"概不退款" |

目标市场在海外时，同样不写假评价：🟢 美国 FTC 的消费者评价与证言规则（16 CFR Part 465，2024-10-21 施行）[原文](https://www.ecfr.gov/current/title-16/chapter-I/subchapter-D/part-465) 禁止编造评价、买卖评价和隐瞒利益关系的证言。其他国家和地区的规定请用户自行确认或咨询律师。

## 行业专项（风险从高到低）

第一版主要服务软件、产品、网站和小程序。如果用户的产品属于下面的行业（例如医疗、教培类 App），对应红线同样适用。

| 行业 | 风险 | 红线 |
| --- | --- | --- |
| 教培（K12） | 极高 | 🟢 面向中小学和幼儿园的校外培训广告一律不得在网络平台刊播，"软文"也不行 [网信办](https://www.cac.gov.cn/2021-11/11/c_1638226444835143.htm)。**不要为 K12 培训做 GEO 内容**；成人职业培训不得写"包过、包就业" |
| 口腔、医美 | 很高 | 🟢 医疗广告须经审查，内容只能是机构名称、地址、科目、接诊时间、电话等基本信息，不得涉及疗效、治愈率、患者证言 [条文](https://www.fadada.com/article/Basics-005648)；🟢《医疗美容广告执法指南》打击"以健康知识、人物专访形式变相发布"和术前术后对比 [原文](https://www.gov.cn/zhengce/zhengceku/2021-11/04/content_5648772.htm)。**"科普文里植入机构名"可能被认定为变相医疗广告**，只做门店基本信息的准确性 |
| 宠物医院 | 较高 | 🟢 须持动物诊疗许可证；兽药广告不得说有效率、不得含"推荐、排序"类评价 [条文](https://www.fadada.com/article/Basics-005493)；不推荐人药兽用 |
| 美业 | 中 | 🟡 水光针、光子嫩肤、洗眉、激光祛色素属医美项目，无医美资质不得宣传 [扬子晚报](https://www.yzwb.net/news/ch/202603/t20260326_335598.html) |
| 健身 | 中 | 预付卡规则同上；🟢 上海等地有办卡金额上限（会籍类单次 ≤5000 元、≤24 个月）[新华网](https://www.news.cn/local/20250114/36ca76116dfb476f9fd613ada70eb7a8/c.html) |
| 汽修、洗车 | 较低 | 🟢 配件须分类标识、明码标价，质保期不得低于法定 [原文](https://www.gov.cn/gongbao/content/2019/content_5437141.htm)；"原厂件、终身质保"须与实际一致 |
| 餐饮、家政 | 较低 | 适用通用红线；餐饮须有食品经营许可证 |

## 写内容前的自检

- [ ] 每一句事实都能对应事实卡上的一条
- [ ] 没有"最好、第一、领先、保证、100%"等无法证明的词
- [ ] 没有编造的评价、案例、数字
- [ ] 不属于上表"极高、很高"风险行业的禁区
- [ ] 发布时按平台要求标注 AI 生成
