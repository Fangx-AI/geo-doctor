# 第 8 步 · 复查：改完到底有没有用

**目的：** 用同样的方法再测一次，诚实地告诉用户哪些变了、哪些没变。

## 什么时候复查

- 可先约在发布后两周复查，作为观察安排，不代表 AI 两周内一定抓取、索引或更新引用；有实际更新证据时可调整。
- 之后每两到四周一次。每次复查前，先确认 `geo/publish-plan.md` 和 `geo/published.csv` 里哪些内容已经发出、发在哪、哪天发的。

## 怎么复查

1. **尽量保持基线条件**：同一个 AI、同一问题集版本和判定标准、每题同样计划次数、同样入口（App 或网页）、联网设置、可见模式、登录状态和地区。记录无法控制的平台或模型变化；条件变动须明确说明可比性限制。
2. 用第 4 步的说明采样（基线是自动采样的，复查也用同样的 AI、模型和参数自动采样；API 批次只和 API 批次比），建立新的唯一批次（例如 `2026-10-28-doubao-retest-01`），原文与快照写到 `geo/runs/<新批次>/`，索引追加到 `geo/runs.csv`；保留基线原文与快照。
3. 按第 5 步分别计算两个批次，报告各自计划次数、有效回答数、拒答和技术失败等数量。分母为 0 写 `NA`；有效回答数不同时，不直接将成功次数相减当作改善，也不为凑相同分母而删除结果。
4. 事实变化时使用新的事实卡快照并标明变化。旧回答按当时事实评分；如需按新事实重新标注，另存结果，不覆盖原标注，也不把产品改价造成的差异算成内容优化效果。

## 写报告

存为 `geo/report-日期.md`：

| 指标 | 基线（日期） | 本次（日期） | 变化 |
| --- | --- | --- | --- |
| **推荐率（A 类）** | 2/8 | 5/8 | +3 次 |
| 提及率（A 类） | 3/8 | 6/8 | +3 次 |
| 竞品甲被推荐 | 7/8 | 6/8 | -1 次 |
| 正确率（B 类） | 2/6 | 6/6 | +4 次 |
| 排除正确率（C 类） | … | … | … |

然后写清楚：

- **变化可能来自哪里**：对照发布表，哪道题的变化可能和哪篇内容有关；AI 新引用了你发的哪个链接。能看到引用你新内容的，才算有力证据。
- **同期的其他变化**：产品改版、投放、媒体报道、平台更新，这些都可能影响结果。
- **没变或变差的题**：同样写进报告，不要只报好消息。
- **样本局限**：20 次采样只能看出大的变化；小幅波动可能只是 AI 回答本身的随机性。

## 不要这样写

- "AI 可见度提升 200%"：样本小、口径不清时不写百分比，写次数。
- 把百分点写成百分比：37.5% → 75% 是增加 37.5 个百分点，不是增加 37.5%。
- 把一次偶然的好结果截图当成结论。

## 每周自动复查（自动驾驶，可选）

用户的项目放在 GitHub 上、又有模型 API Key 时，可以把第 4 到 8 步交给一个每周自动运行的工作流：

```bash
node <技能目录>/scripts/geo-autopilot.mjs action
```

它会写两个文件：

- `.github/workflows/geo-autopilot.yml`：每周一自动运行。依次用 `geo-probe` 重新采样（新批次，不覆盖旧原文），找出"竞品被推荐、你没有"的缺口题，给还没有草稿的缺口各写一篇（默认最多 3 篇，只用已确认的事实），写一份疗效报告 `geo/reports/日期.md`，最后开一个 PR。
- `geo/autopilot.json`：品牌和别名、竞品、要问的 AI、每题问几次、用哪个模型写稿、每周最多写几篇、`autoConfirm`（检查无错误的稿件是否直接标为 confirmed）。

请用户做三件事：在仓库的 Actions secrets 里添加用到的 API Key；在 Settings → Actions → General 勾选 "Allow GitHub Actions to create and approve pull requests"；在 Actions 页面手动运行一次。

告诉用户：**PR 就是审核。** 合并前逐篇读一遍；合并即同意发布标为 confirmed 的稿件（配合第 7 步的 `geo-site action`，事实站会自动更新）；不想发的稿件把 status 改成 draft 再合并。疗效报告只写次数、不写百分比，并注明 API 采样和 App 内可能不同，重要结论仍要在 App 里人工采样确认。

不在 GitHub 上时，可以每周手动跑一次 `geo-autopilot weekly`，效果相同，只是不会开 PR。

## 下一轮

把没改善的题回到第 5 步重新诊断，开新的处方。GEO 是持续的过程，不是做一次就结束。
