# 关键词与场景：题的上一层

一句话：**关键词是买家会输入的东西，问题是把关键词放进一个处境里说成人话。** 先有词，再有题；词错了，题写得再漂亮也是自嗨。

这份文件只做一件事——把已经成熟的搜索侧方法搬过来用，不另发明一套。

## 采用了哪些现成方法

| 要解决的问题 | 现成做法 | 谁在用 |
| --- | --- | --- |
| 一个词到底是"想了解"还是"想买" | **意图四分法**：信息型 / 商业调研型 / 交易型 / 导航型 | Semrush、Ahrefs、SEOmonitor、DataForSEO 都用这套；SEOmonitor 按该词前 10 个落地页的内容来判定意图 |
| 哪些词该合成一个需求 | **按 SERP 重叠聚类**：搜索结果里出现同一批 URL，就是同一个需求 | Ahrefs 的 clustering、KeywordInsights、Cluster AI 都是这个原理 |
| 每个需求该有一个页面 | **主词 + 支撑词 + 聚类缺口**：每簇都要有落地页，没有页面就是 content gap | 关键词聚类的标准收尾动作 |
| 词从哪来 | **种子词**：销售对话、客服工单、销售异议、竞品词、Search Console 里"高曝光低点击"的查询、People Also Ask、搜索下拉 | B2B 关键词研究的通行入口；高曝光低点击专指被 AI 摘要吃掉的那批 |
| B2B 为什么要多种问法 | 采购小组通常 5–16 人，同一需求不同角色问法不同 | Gartner 的采购小组研究，被 B2B 关键词策略普遍引用 |

中文侧的工具只借它们的**词**，不借它们的数字：5118 需求图谱、百度下拉与相关搜索、知乎/小红书/抖音站内搜索（TikHub）。**任何带搜索量的字段都要标来源；查不到就留空，不要用"AI 估算热度"冒充实测**——那个数字签不了字。

## 意图怎么映射到四段旅程

| 意图 | 买家在干什么 | 落在哪段 |
| --- | --- | --- |
| 信息型 informational | 还不确定要不要买，先弄清怎么做 | 探索 |
| 商业调研型 commercial investigation | 在挑、在比 | 选型 / 对比 |
| 交易型 transactional | 准备下单、问价问交付 | 选型 / 对比 |
| 导航型 navigational | 直接找某个牌子 | 口碑 |

映射不是死规矩，是**默认值**。写成别的段不是错，但要在报告里写清为什么——所以工具只给 warn，不给 fail。

## 表的十二列

`geo/keywords.csv`（模板见 `skills/ai-visibility/assets/keywords.csv`）：

| 列 | 填什么 | 不填会怎样 |
| --- | --- | --- |
| `关键词` | 买家会输入的那几个字，短、具体 | 整行不算数 |
| `场景` | 这条业务线：产品线、门店类型、行业 | 覆盖率算不出来（warn） |
| `意图` | 信息型 / 商业调研型 / 交易型 / 导航型 | fail，后面全错 |
| `旅程` | 探索 / 选型 / 对比 / 口碑 | 排不进矩阵（warn） |
| `聚类` | SERP 重叠组的名字，同组共用一个落地页 | warn，同一个需求会被数成几个 |
| `落地页` | 能回答这个词的页面地址；没有就写 `缺` | 汇总成一条"内容任务清单" |
| `来源类型` | 客户原话 / 社区 / 平台追问 / 公开数据 / 构造 | warn |
| `来源` | 具体出处（哪次访谈、哪个帖、哪篇文章） | warn |
| `证据等级` | 1–5（见 questions.md 同一张表） | fail（非 1–5）或 warn（空） |

## 五步

1. **种子**：从知识库的痛点和边界里各取几条，加上客服/销售/工单里的原话。没有原话就明说没有。
2. **扩展**：平台下拉、相关搜索、PAA、竞品官网与评测文章标题。
3. **判意图**：看这个词现在搜出来的前十个结果在讲什么——讲教程是信息型，讲榜单是商业调研型，讲价格和购买是交易型，讲某个牌子是导航型。
4. **聚类**：把搜出来是同一批页面的词合成一组，挑一个当主词，其余当支撑词。
5. **查缺口**：每组问一句"我们哪个页面能回答它？"答不上来的写 `缺`——这就是接下来的内容任务，比凭空想选题靠谱。

## 与问题库的衔接

一个非导航型词，至少生成一道题；一个场景，至少有一个商业调研型或交易型的词。两条都由工具查：

```bash
geo-probe keywords geo/keywords.csv --questions geo/questions.csv --brand "品牌,别名"
```

它会反向报告三件事：**哪些词一题都没有**、**哪些题挂的词不在词表里**、**哪些场景只有探索没有选型**。

## 不做什么

- 不编搜索量。没有工具数据就留空，写"待实测"。
- 不按行业背词表。同一份词表换城市、换品类就失效，能迁移的是"种子的来源"和"判意图的方法"。
- 不让品牌词算进头部可见度。导航型词反映的是"已经知道你的人在问什么"，把它混进总体可见度会让数字虚高（limelit 的做法是保留题目、但把它们从 headline 数字里剔除）。
