# 问法形状：同一件事，用户会怎么问出来

形状（shape）指**怎么问**，与行业无关。两个问题同属 A 类（不带品牌的推荐），一个是"有没有……"，一个是"A 和 B 选哪个"，测到的东西不一样：前者让 AI 自己列名单，后者让它在两个名字之间做判断。

为什么单独管这件事：真实提问里，**商业意图有 78.3% 会触发检索，信息型只有 3.6%**（[From Prompt to Recommendation](https://arxiv.org/abs/2609.23162)，核验于 2026-11-17）。也就是说，形状直接决定 AI 有没有去读你的页面——用一堆"什么是 X"填满题集，测到的基本是模型记忆。

`geo-probe check` 只做三件事：形状必须是下面十种之一、仪表题至少覆盖 5 种、没填形状会提醒你补。它不会替你判断"这个行业该问什么"——那是下面速查表的事。

## 十种形状

### 1. 认知定义

- **测什么：** 模型对品类的既有认知。多数不触发检索，所以对"我的页面有没有被读到"几乎没有信息量。
- **句式：** 「X 是什么」「X 和 Y 有什么区别（概念层面）」「/ what is X」
- **陷阱：** 当仪表题用会大幅拉低"被引用"的机会，却解释不了原因。适合当雷达题，用来判断 AI 对你的品类描述是否过时。

### 2. 品类发现

- **测什么：** 完全不知道你时，AI 会不会把你列进候选。最接近"新增曝光"。
- **句式：** 「有没有能……的工具」「做什么的软件可以……」「/ is there a tool that …」
- **陷阱：** 不加限定条件就退化成泛榜，对所有人一样；必须带人数、预算、平台或地区。

### 3. 选型推荐

- **测什么：** 在多个候选中被选中的能力，比发现自己更靠后一环。
- **句式：** 「30 人团队想……，选哪个」「……用哪个比较省事」「/ which should I pick for …」
- **陷阱：** 容易被写成"最好的 X"——那是诱导措辞，AI 直接给榜单，测不出自然浮现。用"哪个""怎么选"，不用"最好"。

### 4. 直接对比

- **测什么：** 与指定竞品同框时的定位与被选概率。名字由用户给出，所以不测发现，测取舍。
- **句式：** 「A 和 B 选哪个」「A 比 B 好在哪」「/ A vs B for …」
- **陷阱：** 竞品名不要只写最贵的那家，否则测到的是"预算不够时的替代"，不是主战场。

### 5. 找替代

- **测什么：** 从竞品迁移过来的需求，是 GEO 里最容易拿到的一类流量。
- **句式：** 「X 太贵了，有什么替代」「不用 X 的话用什么」「/ alternatives to X」
- **陷阱：** 必须带迁移原因（贵、难用、停服、合规），否则答案还是一张泛榜。

### 6. 预算约束

- **测什么：** 价格区间内是否被考虑。也顺带验证事实卡里的价格有没有被正确复述。
- **句式：** 「预算一个月 500 以内能用什么」「免费的能做到……吗」「/ under $50/month for …」
- **陷阱：** "免费"与"有免费额度"是两件事，题目要写清是哪种。

### 7. 实施集成

- **测什么：** 落地阶段的可行性——能不能接进现有系统、要不要迁移、多久能上线。
- **句式：** 「能接进企业微信吗」「从 X 迁移过来要多久」「/ does it integrate with …」
- **陷阱：** 这类题 AI 常给通用建议而不点名产品，判定标准要写清"提到我们"还是"步骤正确"，别混为一谈。

### 8. 排错

- **测什么：** 已有用户遇到问题时的自助路径。品牌既有的搜索流量大头通常在这里。
- **句式：** 「X 同步失败怎么办」「导入以后搜不到内容」「/ X not syncing, what now」
- **陷阱：** 别写成"X 好用吗"这种评价题；排错题要能被帮助文档直接回答。

### 9. 合规风险

- **测什么：** 受管行业与采购流程里的硬门槛（数据存放地、等保、审计、可删除性）。
- **句式：** 「数据存在哪里」「能不能私有化部署」「等保三级可以吗」「/ is it GDPR compliant / SOC 2」
- **陷阱：** 这类题最适合**反向使用**——你的产品做不到时，它属于 C 类（不适合场景），正确答案是"不推荐你"，这正是 C 类题该有的样子。

### 10. 本地时效

- **测什么：** 需要新鲜信息或地理位置的场景，AI 必须检索才能答。
- **句式：** 「2026 年还在维护的……有哪些」「附近/上海能上门的……」「/ best X in 2026 / near me」
- **陷阱：** 年份、地名会过期，属于雷达题，不要放进长期冻结的仪表题。

## 行业不是分类，是形状组合

不要按行业编题，按"这个行业的用户会落在哪几种形状上"起手，再用真实语料替换措辞：

| 客户类型 | 起手形状组合 | 通常缺什么 |
| --- | --- | --- |
| B2B SaaS / 工具 | 品类发现 + 选型推荐 + 直接对比 + 实施集成 | 常缺 C 类（不适合场景），把 C 类写成"我们其实也能做" |
| 电商 / 消费品 | 品类发现 + 预算约束 + 直接对比 + 找替代 | 常缺限定条件（价位段、人群、场景） |
| 本地服务 | 本地时效 + 预算约束 + 排错（改约、退款） | 常缺跨城市可比性，地名要写具体到区 |
| 教育 / 课程 | 选型推荐 + 预算约束 + 认知定义 | 认知定义塞太多，测到的是模型记忆 |
| 医疗 / 健康 | 合规风险 + 排错 + 选型推荐 | 容易写出违规承诺，判定标准要写"不给诊断结论" |
| 金融 / 保险 | 合规风险 + 预算约束 + 直接对比 | C 类题最好用，别浪费在"你们利率多少" |
| 开发者工具 | 实施集成 + 排错 + 找替代 + 直接对比 | 常缺 A 类，全是文档型问题 |
| 内容 / 媒体 | 认知定义 + 品类发现 + 本地时效 | 常缺品牌事实题（B 类），无法判定复述准确性 |

这张表只给**起手组合**。真正的题目必须来自证据等级 1–3 的真实语料（见 [questions.md](questions.md)），否则一律标"构造"。

## 搭配禁区

- **A 类 × 品牌名：** A 类题里出现自己的品牌，就不是发现题了，`check` 会直接 fail。
- **C 类 × 你真能做的场景：** C 类的价值在于"敢问自己赢不了的题"，写成"我们其实也能做"就退化成一厢情愿。
- **认知定义 × 仪表题：** 多数不触发检索，放进冻结题集会长期压低引用类指标且无法解释。
- **一题两形状：** "多少钱，支持导出吗"同时是预算约束和品牌事实，答对一半时无法判定，拆成两题。

## 填进 CSV

`形状` 一列写下面十个词之一（`check` 认这十个）：

认知定义 · 品类发现 · 选型推荐 · 直接对比 · 找替代 · 预算约束 · 实施集成 · 排错 · 合规风险 · 本地时效

仪表题覆盖不足 5 种时，`check` 会提醒；这时优先补**能触发检索**的形状（品类发现、找替代、直接对比、排错），而不是继续加认知定义。
